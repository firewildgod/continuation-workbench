# 续航台 0.2.1

本版增加官方单价自动填充和联网更新，不需要为已支持的模型逐项输入单价。

- 北京百炼普通按量接口的 Qwen3.8 Flash 与 Max 内置已核实的公开参考价格，旧连接没有填写价格时自动补入。
- 在「用量与费用」的「连接单价」点击「更新官方价格」，从供应商官方模型文档直接读取当前价格；显示来源、核对时间和每个连接的结果。
- 更新不需要 API Key，不调用付费模型，不消耗模型 Token。断网、网页格式变化或价格无法确认时保留原值，并说明失败原因。
- 手动报价保持原值；可以对单个连接选择「使用官方价格」恢复跟随。明确清除的价格不在启动时自动补回。
- 更新只影响后续调用。历史记录继续使用请求开始时保存的价格快照，不因改价重新计算。
- 仅匹配已支持的模型、地域和普通按量端点。包月、国际地域、自定义转发地址与其它模型不自动套用北京公开价格。

Flash 的公开价可以完整估算输入、输出、缓存读取和缓存写入。Max 的显式与隐式缓存读取单价不同，当前无法从统一返回字段确定缓存模式时，不把缓存读取金额当成已确认；未计价标记和价格说明会保留。

单价是公开标准价，赠额、账号折扣、限时活动和实际扣款仍以供应商控制台为准。支持名单外的连接继续使用手动报价。

## 更新程序

等进行中的模型请求结束，退出续航台托盘程序，再打开 0.2.1。数据仍在同目录的 `data`，保留该文件夹即可继续使用原连接。新版启动会自动给旧的未设置价格连接补上已支持模型的内置价。

联网价格刷新在程序内部完成，之后更新价格不需要重新下载安装包。程序安装包尚未进行 Windows 代码签名。
