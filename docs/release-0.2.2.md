# 续航台 0.2.2

工作台增加独立的 Claude Desktop 卡片与侧栏打开入口，和 Claude Code 终端配置分开。

- 桌面卡支持真实 Claude 模型 API 的预览、加密备份后应用、恢复原配置和打开官方桌面。应用前先保存任务并退出 Claude 桌面；续航台不会关闭正在工作的原应用。
- 自动配置按已安装 Claude 2.31226.1.0 的用户级结构核实；未知版本、管理策略、外部修改与不兼容格式停止写入，提供官方配置入口。
- 该桌面版本的模型选择与会话校验拒绝 Qwen、DeepSeek 等非 Claude 模型。选择这类连接会显示原因，保留终端和 VS Code 官方图形扩展的使用路径，不把模型改成伪造的 Claude 名称。
- 桌面使用独立本机网关路由，不影响终端或 Codex 的连接选择。在途请求只阻止自己入口的路由切换。
- 模型目录只在本机读取已选模型，不使用厂商 Key、不调用付费模型、不产生费用记录。实际成功模型请求才显示「已验证」。
- 桌面和终端的请求进入同一费用统计，保留入口来源与请求开始时的单价快照；CSV 增加入口列。
- 桌面配置仅存本机网关令牌，供应商 Key 留在续航台加密库。不会读取或修改会员登录凭据。桌面第三方推理配置会影响 Chat、Cowork、Code。

北京百炼单价自动补全和「更新官方价格」继续保留，网络刷新不消耗模型 Token。

## 使用新版

等本机 API 请求结束，退出旧续航台托盘程序，再打开 0.2.2。保留原目录的 `data`；原连接和费用记录继续使用。

如果使用百炼 Qwen，希望图形界面操作：在终端卡应用对应 API 路由，再导出 VS Code 设置，合并到 VS Code 的用户设置，重启并使用 Claude Code 官方图形扩展。这个路径与官方 Claude Desktop 应用的配置不同。

本版通过 118 项自动化测试，以及 11 项使用隔离配置和本机模拟上游的界面验收。未完成真实官方 Claude Desktop 会话或供应商付费 API 的端到端验收。实际扣款以厂商账单为准；安装包没有 Windows 代码签名。
