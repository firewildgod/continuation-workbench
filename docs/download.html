开始使用

  1. 先安装官方 Codex 或 Claude Code。打开续航台，添加自己的模型 API Key。
  2. 选择工具、供应商与模型，保存并测试；测试会产生正常的小额 API 用量。
  3. 在工作台选择外部 API，预览配置，保存工作并退出对应桌面应用后应用，再重新打开原工具。
  4. 新建聊天确认模型。使用 API 时保持续航台运行，可以收进系统托盘。
费用是厂商实际扣款吗？

费用按本机收到的 Token 用量和单价估算，不是实时账单。只覆盖本机网关及连接测试；会员内调用、赠额、折扣、套餐扣减及其它电脑的调用不在其中。实际扣款请在供应商控制台确认。

Claude 桌面也能自动切换吗？

Claude Desktop 和 Claude Code 终端有独立配置入口。桌面自动适配已核实版本及真实 Claude 模型；当前核实版本会拒绝 Qwen 等非 Claude 模型，国产模型可以使用终端或 VS Code 官方图形扩展。实际请求成功后才标记桌面已验证。

复制程序到另一台电脑，需要做什么？

便携程序和连接参数可复制。API Key 与原配置使用 Windows 系统加密，换 Windows 用户或电脑后需要重新输入 Key、重新应用配置。

软件会保存聊天内容吗？

费用记录只保存连接、模型、时间、结果、Token 和单价，不保存提示词、回答、项目文件或密钥。请求由所选模型供应商处理，没有自动上传费用报表或后台遥测。
