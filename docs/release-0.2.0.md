# 续航台 0.2.0

续航台是 Codex 桌面和 Claude Code 的连接伴侣。原来的编辑、聊天和项目工作继续在官方工具中进行；这里管理供应商、API 路由、费用和配置备份。

## 本次更新

- 用今日、本月费用摘要替换单独的大预算表单；增加近 7 日趋势、按连接汇总和调用明细。
- 直接读取 Responses / Anthropic JSON 与 SSE 中的 Token 用量，分别统计普通输入、缓存输入和输出。连接测试也纳入记录。
- 每次调用保存当时的人民币单价，后续改价不重算旧记录。没有完整用量或没有报价时显示未计价。
- 普通百炼和 Token Plan 分开；切换 Codex / Claude Code 自动匹配接口地址和协议。
- 百炼普通接口、智谱和 Kimi 等目录提供模型候选，仍可手动输入准确模型 ID。
- 错误地址、AccessKey ID、套餐 Key 混用和不同 HTTP 错误提供具体处理提示。
- 明确 Claude Code 终端 / VS Code 与 Claude 桌面的独立配置方式。
- 导出带北京时间、Token 和单价来源的 CSV 费用报表；原有配置预览、加密备份、回滚继续保留。

## 费用的含义

费用页展示经过本机网关的调用和连接测试，金额按用量和已配置单价估算，不是厂商实时账单。不包括会员内的调用、旧版本历史调用、其它电脑或绕过本机网关的请求。免费赠额、折扣、阶梯、工具额外收费及套餐扣减可能使估算与账单不同。通过官方控制台核对实际扣款。

默认报价只在已验证的模型和地域上使用。其他模型可以填写人民币每百万 Token 单价；海外美元价格需要自行换算。无法确认缓存费率时保留未计价，不按零元计算。预算是提醒目标，不会在达到目标时自动停止模型请求。

## 安装与升级

- 便携版：把 EXE 放在固定文件夹运行；数据位于程序旁的 `data` 文件夹。
- 解压版：解压 ZIP 后运行 `续航台.exe`。
- 安装版：运行 setup EXE，安装向导允许选择目录并创建桌面快捷方式。
- 从 0.1.1 升级：在没有请求执行时，从旧续航台托盘菜单退出。把新版本放在旧版本所在目录，保留原 `data`，再打开新版本。不要同时运行两份占用相同端口的管理器。
- 换电脑或 Windows 用户：程序和连接参数可复制，密钥使用 Windows 系统加密，需重新输入密钥并应用配置。

安装包尚未购买 Windows 代码签名证书。发布目录会提供 SHA-256 校验值。软件不包含任何用户的 API Key、会员凭据或调用记录。

## 隐私

本地费用账本只保存时间、连接名称、工具、模型、请求结果、Token 数和单价；不保存提示词、项目文件内容、模型回答或密钥。API 请求按所选连接发送到该供应商，生成和测试调用会产生正常的 API 用量。软件没有自动上传费用报表或后台遥测。

续航台不是 OpenAI 或 Anthropic 的官方产品。供应商名称用于说明接入目标；供应商的价格、账号权限和协议兼容性以其官方文档为准。
